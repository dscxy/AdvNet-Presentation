# Language conventions

Project files — documents, code comments, commit messages, and similar text — are written in English.

Conversational replies to the user follow the language of the user's most recent message, unless the user asks for a different language.

# Commit conventions

Use Conventional Commits: `<type>[optional scope]: <description>`. Write commit messages in English.

Before starting a task, check `git status`. If it reports any uncommitted changes, including staged, unstaged, and untracked files, do not begin task work without the user's explicit approval.

After each task round, stage and commit the changes made during that round unless the user explicitly asks not to.

# Objective

Prepare the slides and scripts of a presentation. The presentation mainly focuses on the paper [AdvNet: Revealing Performance Issues in Network Protocols by Generating Adversarial Environments](<docs/AdvNet - Revealing Performance Issues in Network Protocols by Generating Adversarial Environments.pdf>).

# Slides format

The slides should be created using the LaTeX beamer package. The minimum acceptable font size is 18pt, and larger sizes are preferred.

# Mandatory presentation requirements

The course syllabus mandates the following presentation requirements:

1. The primary goal of the presentation is to help everyone gain a deeper understanding of the paper while fostering critical thinking and a lively discussion.

2. The presentation should be self-contained and accessible to students who did not read the paper or found it difficult to understand. It should:
   - provide additional background on the concepts you found most challenging, going beyond the paper when necessary;
   - highlight results you found especially interesting or surprising, without attempting to explain every figure; and
   - engage the class by posing questions that prompt discussion of the paper's design, results, or limitations.

3. The presentation should contain **25 minutes** of content _if_ delivered without interruption. Time for engaging with the audience or taking questions is not included.
